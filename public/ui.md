"너는 전문 웹 퍼블리셔이자 프론트엔드 개발자야. HTML5와 Tailwind CSS(CDN 방식)를 사용하여 세련되고 모던한 의류 쇼핑몰의 메인 페이지(index.html)를 만들어줘.

[요구사항]
1. 상단 네비게이션 바: 로고, 검색창, 장바구니 아이콘, 카테고리 메뉴를 포함해줘.
2. 카테고리 구성: 아우터, 상의, 하의, 악세사리 4가지로 탭이나 메뉴를 구성해줘.
3. 메인 배너: 쇼핑몰의 감성을 보여주는 큰 이미지 배너 공간과 텍스트를 넣어줘.
4. 상품 리스트 (Grid): 각 카테고리별로 예시 상품이 4개씩 반응형(모바일 2열, 데스크톱 4열)으로 보이게 해줘. 상품 카드는 이미지(Unsplash 가상 이미지), 상품명, 가격, '장바구니 담기' 버튼으로 구성해줘."
